2Create a new template

  1. Set Draft source to New template.
  2. Choose the clean production JPEG.
  3. Enter the Template ID and user-facing label.
  4. Choose category, position, and accent color.

Template ID: lowercase letters, numbers, and hyphens. Examples: welcome-new-member, cancun-2027, jacksonville-couple.

3Prepare the Canva file

Upload the clean JPEG exported from Canva.

Remove only: the sample/person photo and dynamic placeholder name.

Keep: logos, event text, permanent wording, borders, backgrounds, and decorations.

Screenshot placeholder: an approved before/clean Canva pair is needed. No source artwork was changed or invented for this guide.

4Set the photo area

  1. Select Edit overlays.
  2. Select Draw photo region and drag over the flyer.
  3. Select Move/resize photo to adjust it.
  4. Choose Rectangle or Circle / ellipse.

The visible numbers are for advanced fine-tuning. Position the area visually first.

5Set the name

Select Move name/width. Drag the name anchor to position it and the width handle to set its available width.

Use the Studio's controls for preview name, position, width, font, weight, size, color, alignment, uppercase/preserve case, tracking, max lines, line height, vertical alignment, and word wrapping.

6Test the template

  1. Check Short.
  2. Check Two-word.
  3. Check Long.
  4. Test a sample photo when available.
  5. Use Edit overlays to position things and Production preview to see the actual result.

7Validate

  1. Select Validate template.
  2. Wait for the result.
  3. If it fails, correct the reported issue and validate again.

Validation does not publish. Success says “Template is valid for hosted publication.”

8Publish

Publish is the action that changes the live flyer generator.

  1. Validate successfully.
  2. Select Generate review artifact if needed.
  3. Select Prepare promotion.
  4. Review template, category, order, artwork, preview, and plan.
  5. Type PROMOTE.
  6. Select Publish template.
  7. Wait for success and record the identifier shown.

The current hosted Studio still uses the typed PROMOTE confirmation. Deployment may take a short period.

9Verify the live template

Open viago-flyer-generator.pages.dev

  • Correct category and position
  • Correct thumbnail
  • Photo area works
  • Normal and long names look right
  • Downloaded PNG looks right

10Edit an existing template

  1. Set Draft source to Existing template.
  2. Choose the exact template.
  3. Make approved changes.
  4. Preview, validate, prepare the plan, type PROMOTE, and publish.

Editing and previewing do not affect the public generator until Publish is confirmed.

11Retire an old template

Template retirement is not yet available from the Studio interface. Contact the platform owner. Do not overwrite an old template to hide it.

12If something looks wrong

  • Do not repeatedly publish trying to fix it.
  • Stop and reopen the current template.
  • Confirm artwork and Production Preview.
  • Validate again.
  • If unsure, contact the platform owner.

13Quick checklist

Before Publish

  • Clean JPEG uploaded
  • Correct template name
  • Correct category and order
  • Photo area checked
  • Short name checked
  • Long name checked
  • Production Preview checked
  • Validation passed

After Publish

  • Appears in public generator
  • Photo works
  • Name works
  • Download checked
